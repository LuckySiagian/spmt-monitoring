SLIDE 3: SOLUSI YANG DITAWARKAN (SPMT MONITORING)

SPMT Monitoring: Aplikasi pemantau kesehatan web service otomatis.

  • Deteksi Multi-Protokol: Mendeteksi tidak hanya HTTP, melainkan DNS resolver, status port TCP, dan ICMP Ping secara berkala.
  • Dasbor NOC Dinamis: Menyajikan topologi jaringan real-time interaktif (Star, Tree, dan 3D Globe).
  • Notifikasi Cepat: Mengirim alarm otomatis melalui Email dan Telegram saat terjadi kegagalan sistem.
  • Ringan & Cepat: Menggunakan backend bahasa Go yang berukuran sangat hemat memori.
🗣️ Narasi Pembicara (Apa yang Anda ucapkan):
"Solusi yang kami rancang adalah SPMT Monitoring. Aplikasi ini bekerja secara mandiri melakukan pengecekan kesehatan server target menggunakan protokol DNS, Ping, TCP, dan HTTP secara berkala. Semua status disinkronisasikan ke dasbor NOC secara instan, lengkap dengan notifikasi cepat ke Telegram dan Email."
SLIDE 4: ARSITEKTUR TEKNOLOGI
  • Backend (Go Engine):
    • Efisiensi konkurensi dengan Goroutine (Worker Pool Pattern).
    • WebSocket server untuk broadcast data instan tanpa HTTP polling.
  • Frontend (React Client):
    • UI dinamis berbasis React 18.
    • Visualisasi topologi menggunakan HTML5 Canvas performa tinggi.
  • Database (PostgreSQL):
    • Menyimpan konfigurasi situs, riwayat SLA harian, log insiden, dan audit trail operator.
🗣️ Narasi Pembicara (Apa yang Anda ucapkan):
"Dari segi teknologi, sistem menggunakan arsitektur 3-tier. Di bagian backend kami menggunakan Go karena sangat andal dalam menangani ratusan koneksi secara paralel lewat Goroutine dengan konsumsi memori di bawah 20MB. Frontend dibangun menggunakan React yang terhubung ke server via WebSocket agar data mengalir terus-menerus tanpa perlu memuat ulang halaman."
SLIDE 5: LOGIKA CERDAS SISTEM
  1. Anti-Flapping (Brake Alarm Palsu): Kegagalan berjadwal harus terkonfirmasi 3 kali berturut-turut sebelum dinyatakan benar-benar offline, menghindari alert palsu dari fluktuasi jaringan sesaat.
  2. Quorum Jaringan Lokal: Jika pengecekan gagal, backend melakukan validasi internet mandiri ke 3 DNS publik terpisah guna menjamin server lokal tidak sedang hilang koneksi.
  3. Refresh Manual Instan: Tombol refresh di dasbor diprogram memotong masa tunggu anti-flapping dan pengecekan lokal untuk menyajikan status aktual secara instan.
  4. Deteksi Bypass WAF/Anti-Bot: Mampu membedakan pemblokiran otomatis pada bot (HTTP 403/429/503 Cloudflare) dengan website yang memang down secara riil.
🗣️ Narasi Pembicara (Apa yang Anda ucapkan):
"Salah satu keunggulan sistem ini adalah memiliki kecerdasan dalam mendeteksi kegagalan. Sistem memiliki pelindung alarm palsu lewat anti-flapping dan cek kuorum jaringan server sendiri. Kami juga baru saja menyempurnakan fitur refresh manual. Jika operator mendeteksi isu, tombol refresh akan mengabaikan jeda flapping dan langsung memperbarui status serta last_checked saat itu juga."
